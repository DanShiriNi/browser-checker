# 🧭 Браузеры — оценка и тир-лист

Одностраничное веб-приложение для сравнения браузеров по множеству критериев: удобство, безопасность, производительность, дизайн, блокировка рекламы, потребление памяти и другие.

Программа автоматически вычисляет рейтинг, формирует **тир-лист** и показывает **топ‑5** браузеров с учётом защиты конфиденциальных данных.

## 🚀 Как использовать

### 1. Оценка браузеров
- Переключайтесь между браузерами с помощью **⬆ / ⬇** (сбоку от формы).
- Переключайтесь между категориями с помощью **⬅ / ➡**.
- Заполняйте поля:
  - **Да/Нет** — клик по переключателю.
  - **Смайлики** — выберите степень (от «вообще не» до «полностью»).
  - **Числа** — введите значение (например, время настройки, потребление ОЗУ). Рядом автоматически появится оценка («быстро/медленно», «мало/много»).

### 2. Просмотр результатов
- Нажмите **«📊 Результаты»** в шапке.
- Переключайтесь между вкладками:
  - **Сводка** — таблица со всеми параметрами.
  - **Тир-лист** — распределение браузеров по уровням (можно перетаскивать).
  - **Топ-5** — лучшие браузеры с защитой и без неё.

### 3. Управление данными
- **Сбросить всё** — очищает все оценки и тир-лист.
- **Сохранить в CSV** — экспорт текущего состояния (оценки + тир-лист).
- **Импортировать сохранение** — загрузка ранее сохранённого CSV-файла.

## 🧠 Как работает расчёт баллов

- Каждый параметр приносит **1 балл**, если ответ положительный:
  - `Toggle` = `true`
  - `Смайлик` = 2 или 3 (почти полностью / полностью)
  - `Число` — если значение удовлетворяет условию (например, < 600 МБ для ОЗУ)
- **Итоговый балл** = сумма всех положительных ответов.
- **Безопасность** — количество положительных ответов в категории «Безопасность» (максимум 4).
- Уровень тир-листа определяется **автоматически**:
  - Если безопасность >= 3:
    - балл ≥ 20 → `5+`
    - балл ≥ 15 → `5`
    - балл ≥ 10 → `4`
    - иначе → `3`
  - Если безопасность < 3:
    - балл ≥ 15 → `5 (без защиты)`
    - балл ≥ 10 → `4 (без защиты)`
    - балл ≥ 5 → `3`
    - иначе → `2 (самые ужасные)`

## 📂 Структура данных

### Категории и параметры

| Категория | Параметры (примеры) |
|-----------|----------------------|
| **Доступность** | Бесплатный, открытый исходный код |
| **Удобство** | Настройка, менеджер паролей, группировка вкладок, работа стримов/Figma/DRM |
| **Дизайн** | Опрятный, красивый, кастомизация |
| **Безопасность** | Отключение отправки данных, замена поисковика, отсутствие ИИ |
| **Блокировка рекламы** | Скрывает рекламу, поддержка uBlock Origin |
| **Дополнительные фишки** | Поиск по фото, перевод текста/видео, пересказ |
| **Производительность** | Скорость загрузки (индекс), отсутствие лагов на GIF |
| **Потребление ОЗУ** | Потребляемая память на пустой странице, YouTube, Дзен, Geometry Dash (первые вкладки не закрываем) |

## 🛠 Технические детали

- **Чистый HTML/CSS/JavaScript** — без внешних зависимостей.
- **Хранение данных** — в памяти (при перезагрузке данные сбрасываются, используйте CSV для сохранения).
- **Drag‑and‑drop** — нативная поддержка (работает на десктопе и мобильных браузерах с touch‑событиями).
- **Адаптивность** — медиа-запросы для экранов ≤ 720px и ≤ 440px.
- **Иконки браузеров** — встроены в HTML как скрытые SVG-элементы.

## 📥 Установка и запуск

1. Скачайте файл `BrowserCheck.html`.
2. Откройте его.
3. Готово! Все данные хранятся локально в оперативной памяти.
